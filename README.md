# FPS_GADE_POE
Engine: Unreal Engine 5.8

Playable build: see Releases → v1.0 (run FPS_GADE_POE.exe)
**Open the project: double-click FPS_GADE_POE.uproject (click Yes if asked to rebuild modules)**
Start level: MainMenu

Controls: WASD move, Space jump, Mouse aim/shoot, 1/2 swap weapons, R reload (pistol),
E pick up, Esc pause
